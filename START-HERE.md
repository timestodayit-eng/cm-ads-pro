# Fresh-install quick start

**For a NEW setup, open `FRESH-INSTALL.md` and use `sql/FRESH-INSTALL-v0.3.sql` in a new empty database.** This is the full source, not an upgrade-only patch.

For existing installs wanting to preserve users and data, use `UPGRADE.md` instead.

No default admin username/password exists; create one with `/setup`. Real Meta ad publishing is not implemented in version 0.3.0.
